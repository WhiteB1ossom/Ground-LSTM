# 노트북으로 옮긴 다음

1. ZIP을 노트북의 `C:\ground-laptop` 같은 폴더에 **전부 압축 해제**한다. ZIP 안에서 파일만 바로 실행하지 않는다.
2. 노트북 Codex에서 `setup-laptop.cmd`와 `src` 폴더가 있는 **프로젝트 폴더를 작업 폴더로 연다.**
3. 아래 문장을 그대로 보내면 된다.

> 이 폴더의 LAPTOP_CODEX_HANDOFF.md를 읽고 Windows 노트북 실행 환경을 준비해줘. 필요한 Python·런타임 확인, 가상환경 생성, 고정 버전 패키지 설치, 실제 모델 검증, 시연 서버 실행까지 진행해줘. 모델 재학습은 하지 말고 기존 모델을 사용해줘. 오류가 나면 원인을 해결하고 실행 확인까지 마무리해줘.

처음 환경을 설치할 때는 인터넷이 필요하다. 환경과 모델 검증이 끝나면 **`run-demo.cmd`를 더블클릭**해서 시연한다. 매번 다시 설치하거나 학습할 필요는 없다.

Codex 없이 직접 준비하려면 `setup-laptop.cmd`를 더블클릭해도 된다. Python 3.12 x64가 없으면 먼저 설치해야 하며, Windows 시스템 설치 과정에서 관리자 승인이 요구될 수 있다. 자세한 내용은 [노트북 Codex 인수인계](LAPTOP_CODEX_HANDOFF.md)에 있다.

이 ZIP에는 코드·설정·테스트·문서·기존 발표자료·선택된 두 모델·합성 Test 입력이 들어 있다. 과거 실험 전체와 가상환경은 포함하지 않는다. 기존 발표자료는 이전 실험 버전이므로 최신 서버 모델 수치는 [서버 안내](docs/equipment-server-20261015.md)를 기준으로 확인한다.
