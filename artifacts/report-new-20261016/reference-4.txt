수행내용
LSTM 시계열 모델 설계 및 학습·성능 평가
4회차에서는 이전에 검토한 센서 데이터 전처리와 시계열 입력 구성을 바탕으로, 낙뢰방호장치의 센서 상태를 분류하기 위한 LSTM 모델과 학습·평가 프로그램을 구현하였다. 이번 실행은 합성 데이터를 이용하여 프로그램의 동작을 확인한 것으로, 실제 낙뢰 감지 성능을 입증하는 실측 평가와는 구분하였다.
먼저 교육계획서 마지막 슬라이드에 제시된 센서별 측정범위, Threshold 기준값, 측정주기를 확인하였다. 대지전위의 기준값은 2, 누설전류는 1 mA, 제한소자 온도는 25 ℃, 상대습도는 60%로 기록하였다. 누설전류는 입력 단위를 A로 통일하기 위해 1 mA를 0.001 A로 변환하였다. 또한 대지전위와 번개센서는 100 ms, 누설전류와 입력전압은 1초, 제한소자 온도는 60초, 상대습도와 외기온도는 60분 주기로 구분하여 표준 센서 설정에 반영하였다.
다만 표에 제시된 기준값만으로 위험 상태를 자동 결정하지는 않았다. 특히 제한소자 온도의 25 ℃가 절대온도인지, 기준 온도 대비 상승량인지 확인이 필요하다고 판단하였다. 이에 기준값은 출처와 함께 보존하고, 비교 방향과 동작 의미가 확정되지 않은 항목은 자동 위험 판정에 적용하지 않았다.
학습 데이터는 train, validation, test로 분리하였다. 동일한 이벤트가 서로 다른 분할 구간에 포함되지 않도록 하고, 정규화 기준은 train 데이터만으로 계산하여 평가 데이터가 학습 과정에 유입되는 것을 방지하였다. 또한 미래 관측값을 사용하지 않고 현재까지의 센서 데이터로 입력 특징을 구성하였다.
이번 합성 데이터 실험에서는 train 441개, validation 147개, test 294개의 시퀀스를 사용하였다. 각 시퀀스는 100 ms 간격의 16개 시점과 센서값·결측 표시를 포함한 20개 특징으로 구성하였다. 이는 약 1.6초의 입력 구간으로, 학습 프로그램의 실행을 확인하기 위한 데모 설정이다. 별도의 표준 전처리 설정에는 초기 입력 길이를 64개 시점으로 구성하고, 느린 센서의 측정값 나이를 함께 사용하도록 설계하였다. 해당 표준 설정의 재학습은 실제 데이터와 정답 label을 확인한 후 진행할 예정이다.
LSTM 모델은 hidden unit 16개와 1개의 단방향 LSTM 계층으로 구성하였다. 출력은 정상과 위험을 구분하는 이진 분류 방식으로 설계하였다. 또한 LSTM의 성능을 비교할 수 있도록 Logistic Regression 모델을 함께 학습하였다. 이를 통해 복잡한 모델을 사용하는 것이 실제로 성능 향상에 도움이 되는지 확인하고자 하였다.
학습에는 Adam optimizer와 초기 학습률 0.001, batch size 32를 사용하였다. 데모의 최대 학습 횟수는 50회로 설정하고, validation loss가 정체되면 학습률을 낮춘 뒤 개선이 계속 없을 경우 조기 종료하도록 구성하였다. 최종 평가에는 validation loss가 가장 낮은 시점의 모델을 저장하여 사용하였다. 이번 실행에서는 validation loss가 마지막까지 감소하여 조기 종료 없이 50회 학습을 완료하였다.
학습 과정에서 train loss는 약 0.676에서 0.021로, validation loss는 약 0.629에서 0.019로 감소하였다. 두 곡선이 함께 감소하는 모습을 통해 합성 데이터에 대한 학습이 진행되었음을 확인하였다. 다만 마지막 학습 시점까지 개선이 이어졌으므로, 최대 학습 횟수에 도달했다는 사실만으로 모델의 수렴이나 최적화를 확정하지 않았다.
성능 평가는 validation 데이터에서 판단 임계값을 선택한 후, 해당 값을 고정하여 test 데이터에 적용하는 방식으로 진행하였다. 평가 지표는 Precision, Recall, F1, PR-AUC와 미탐지 수, 오경보 수를 사용하였다. 정상과 위험의 비율이 달라질 수 있으므로 정확도 하나만으로 모델을 평가하지 않도록 구성하였다.

LSTM은 test의 위험 시퀀스 90개를 모두 위험으로 분류하여 미탐지는 발생하지 않았다. 그러나 정상 시퀀스 204개 중 46개를 위험으로 분류하여, 정상 데이터에 대한 오경보 비율은 약 22.55%로 나타났다. 따라서 이번 결과는 위험을 놓치지 않는 측면에서는 양호했으나, 정상 상태를 위험으로 판단하는 문제를 추가로 검토해야 한다는 것을 보여주었다. 여기서 평가 개수는 입력 시퀀스 수이며, 실제 낙뢰 발생 횟수를 의미하지 않는다.
Logistic Regression은 이번 합성 데이터에서 모든 test 시퀀스를 올바르게 분류하였다. Validation에서도 두 모델의 평가 점수가 같았기 때문에, 프로그램은 더 단순한 Logistic Regression을 비교 결과의 추천 모델로 기록하였다. 이는 이번 실험에서 LSTM의 우수성이 입증된 것은 아니며, 실제 데이터에서도 비교 모델을 함께 평가할 필요가 있음을 보여준다.
학습된 모델, 정규화 정보, 특징 순서, 학습 이력과 평가 결과는 파일로 저장하였다. 저장된 모델을 다시 불러와 동일한 임계값으로 재평가하였으며, 원래 평가 결과와 일치함을 확인하였다. 데이터 검사, 전처리, 링 버퍼, 모델 학습 및 재평가를 포함한 전체 자동 테스트 125개도 통과하였다.
기존에 구현한 링 버퍼는 고정된 크기로 최신 센서 특징을 유지하고, 유효한 시퀀스를 생성하는 기능을 수행한다. 현재는 데이터 관리와 시퀀스 생성까지 구현되어 있으며, 실시간 모델 추론 및 위험 판단과의 연결은 후속 단계에서 진행할 예정이다.
향후에는 기업에서 확인한 센서 기준값의 의미와 실제 측정 데이터의 정답 label을 바탕으로 표준 설정에 맞춰 전처리와 학습을 다시 수행할 계획이다. 이후 모델 변환과 MCU의 메모리·실행시간 측정, 링 버퍼와 실시간 추론의 연결을 진행하고자 한다. 이번 회차에서는 데이터 전처리부터 모델 학습, 성능 평가, 모델 저장 및 재평가까지의 소프트웨어 흐름을 구현하고 합성 데이터로 동작을 검증하였다.
