데이터 전처리 계획
3주차에서는 제공받은 실측 낙뢰 데이터와 실습 과정에서 얻은 센서 데이터를 LSTM 모델에 사용할 수 있도록 전처리하는 과정을 진행하고자 한다. 교육계획서에서는 실제 낙뢰 데이터와 실습 모듈에서 발생시킨 데이터를 비교하고, 정규화(Normalization), 시계열 단위(Time-step) 분할 등을 통해 LSTM 학습용 데이터셋을 구성하도록 제시되어 있다.
먼저 센서별 데이터의 구조와 측정주기를 확인할 예정이다. 제공된 자료를 확인한 결과 대지전위, 누설전류, 제한소자 온도, 상대습도, 외기온도, 입력전압, 번개센서 등 여러 종류의 데이터가 존재하며, 센서마다 측정범위와 수집주기가 다르게 설정되어 있다. 따라서 데이터를 바로 LSTM에 입력하기보다는 각 센서 데이터를 동일한 시간 기준으로 정리하는 과정이 필요하다고 판단하였다.
이후 데이터 수집 과정에서 발생할 수 있는 결측값이나 통신 오류값 등을 확인하고 정리하고자 한다. 이 과정에서 전압이나 전류의 급격한 변화와 같이 실제 낙뢰 특성일 수 있는 데이터는 단순한 이상값으로 판단하여 삭제하지 않고, 기업에서 제공한 Threshold 기준과 실측 낙뢰 데이터를 참고하여 센서 오류인지 실제 변화인지 구분할 예정이다.
센서별 측정단위와 데이터 범위가 서로 다르기 때문에 정규화 과정도 진행할 예정이다. 예를 들어 전압, 전류, 온도, 습도는 각각 값의 범위가 다르므로 데이터를 일정한 범위로 변환하여 특정 센서값의 크기가 LSTM 학습에 지나치게 큰 영향을 주지 않도록 구성하고자 한다.
정리가 완료된 데이터는 일정한 Time-step 단위로 나누어 LSTM 입력 데이터로 사용할 예정이다. LSTM은 한 시점의 값만 사용하는 것이 아니라 일정 시간 동안의 데이터 변화 흐름을 분석하기 때문에, 낙뢰 발생 이전부터 감지 시점까지의 연속적인 데이터를 하나의 시계열 구간으로 구성하는 방법을 검토하였다.
또한 이전에 검토한 Ring Buffer 방식을 향후 실시간 시스템에 적용하는 방향도 함께 고려하였다. Ring Buffer는 최근 일정 시간의 데이터만 임시로 저장하고 오래된 데이터는 새로운 데이터로 계속 덮어쓰는 방식이다. 평상시에는 정상 데이터를 계속 저장하지 않고 최근 데이터만 유지하다가, 낙뢰 위험 또는 이상 징후가 확인되는 경우 해당 시점의 전후 데이터를 별도로 저장하는 구조로 활용할 수 있다.
이를 적용하면 다음과 같은 형태로 데이터를 구성할 수 있다.
낙뢰 감지 전 데이터 → 낙뢰 감지 시점 → 낙뢰 감지 후 데이터
낙뢰 발생 전 데이터는 위험상태로 접근하는 과정에서 센서값이 어떻게 변화하는지를 학습하는 데 활용하고, 낙뢰 발생 후 데이터는 LSTM의 판단 이후 실제 센서값이 어떻게 변화하였는지를 확인하는 데 활용하고자 한다. 이를 통해 낙뢰 전 데이터는 예측 및 사전 판단에 활용하고, 낙뢰 후 데이터는 판단 결과를 검증하거나 향후 모델을 개선하기 위한 자료로 활용할 수 있을 것으로 판단하였다.
3주차에서는 Ring Buffer를 실제 시스템에 구현하는 것보다는, 향후 해당 구조를 적용할 수 있도록 센서 데이터 정리 → 시간축 정렬 → 결측 및 오류 데이터 확인 → 정규화 → 낙뢰 전·후 구간 추출 → Time-step 구성의 순서로 전처리 기준을 정하는 것을 목표로 한다.
전처리가 완료된 데이터는 4주차 LSTM 모델 설계 및 학습에 활용하고, 실제 낙뢰 발생 패턴이나 장비 상태를 어느 정도 구분하고 예측할 수 있는지 확인할 예정이다. 이는 3회차의 데이터 전처리 단계와 4회차의 LSTM 알고리즘 설계 단계가 이어지도록 구성한 것이다.
